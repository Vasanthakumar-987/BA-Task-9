# Business Sales Analysis Dashboard – Tableau

[**View Dashboard**](https://public.tableau.com/views/BUISSESNESSANALTYISDASHBOARD/Dashboard1?:language=en-US&:sid=&:redirect=auth&:display_count=n&:origin=viz_share_link)

## Project Overview

This project uses Tableau to analyze business sales across months, categories, products, and stores. Interactive filters help users explore sales performance.

## Dataset

* **Name:** Business Sales Trend Dataset
* **Records:** 4,525
* **Columns:** Date, Store, Category, Product, Quantity, Unit Price, Discount (%), and Sales

## Tools Used

* Tableau Public
* CSV Dataset

## Dashboard Features

* **Sales Trend Over Time:** Monthly sales using a line chart.
* **Sales by Category:** Category comparison using a bar chart.
* **Top 5 Products by Sales:** Product contribution using a pie chart.
* **Sales by Store:** Store comparison using a bar chart.
* **Filters:** Product, Category, Month, Sales, and Store.

## Key Insights

* Electronics has the highest category sales.
* May has the highest monthly sales in the displayed period.
* Trichy leads sales among the displayed stores.
* Store-wise sales are relatively close.

## Conclusion

This dashboard helps users understand sales trends and compare product, category, and store performance through interactive visualizations.
